# 291 Group Homebrew tap

Homebrew formulae and casks for 291 Group's open source tools.

## LAN Orangutan

Network discovery and device inventory for your LAN.

    brew install 291-group/tap/lan-orangutan

Requires nmap, which Homebrew installs as a dependency.

## LAN Sheriff

Watches which servers your network talks to.

    brew install --cask 291-group/tap/lan-sheriff

Both are published automatically by each project's release workflow.
